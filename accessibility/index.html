Accessibility Statement

Last updated: November 2026

Communication access matters to us, and that includes this website. Tribe Speech Therapy aims to meet the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA.

What we've done

  • Clear headings and page structure for screen readers
  • Text alternatives for meaningful images
  • Color contrast chosen for readability
  • Full keyboard navigation, with visible focus indicators
  • A layout that works on phones, tablets, and computers and supports browser zoom

Need help or found a problem?

If you have trouble using any part of this website, or need information in another format, please call (310) 526-3331 or email Elora@tribespeechtherapy.com. We'll do our best to help and to fix the issue.
